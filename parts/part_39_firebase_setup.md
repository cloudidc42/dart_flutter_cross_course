# Part 39: Firebase Integration

## Firebase คืออะไร

Firebase เป็น platform จาก Google สำหรับ mobile และ web app development ให้บริการ backend services ต่างๆ เช่น Authentication, Database, Storage, Hosting และอื่นๆ

### Firebase Services ที่ใช้บ่อยใน Flutter
- **Authentication** - Login/Register
- **Firestore** - NoSQL cloud database
- **Realtime Database** - Real-time sync database
- **Storage** - File storage
- **Cloud Functions** - Serverless functions
- **Analytics** - App analytics
- **Crashlytics** - Crash reporting
- **Cloud Messaging** - Push notifications

## Firebase Project Setup

### ขั้นตอนที่ 1: สร้าง Firebase Project

```
1. ไปที่ https://console.firebase.google.com
2. คลิก "Add project" หรือ "Create a project"
3. ตั้งชื่อ project (เช่น "my-flutter-app")
4. เลือกว่าจะใช้ Google Analytics หรือไม่
5. คลิก "Create project"
```

### ขั้นตอนที่ 2: Add App to Firebase

```
สำหรับ Android:
1. คลิก Android icon ใน Firebase console
2. ใส่ Android package name (เช่น com.example.myapp)
3. ใส่ App nickname (optional)
4. ใส่ Debug signing certificate SHA-1 (optional แต่จำเป็นสำหรับ Google Sign In)
5. ดาวน์โหลด google-services.json
6. วางไฟล์ที่ android/app/
7. เพิ่ม Firebase SDK ใน build.gradle

สำหรับ iOS:
1. คลิก iOS icon ใน Firebase console
2. ใส่ iOS bundle ID (เช่น com.example.myapp)
3. ดาวน์โหลด GoogleService-Info.plist
4. วางไฟล์ใน ios/Runner/
```

## FlutterFire CLI

### ติดตั้ง FlutterFire CLI

FlutterFire CLI ช่วย configure Firebase สำหรับ Flutter app โดยอัตโนมัติ

```bash
# ติดตั้ง Firebase CLI
npm install -g firebase-tools

# Login to Firebase
firebase login

# ติดตั้ง FlutterFire CLI
dart pub global activate flutterfire_cli
```

### Configure Firebase ด้วย FlutterFire CLI

```bash
# ใน directory ของ Flutter project
flutterfire configure

# FlutterFire CLI จะ:
# 1. แสดง list ของ Firebase projects
# 2. ให้เลือก project
# 3. เลือก platforms (Android, iOS, Web, macOS)
# 4. สร้างไฟล์ firebase_options.dart โดยอัตโนมัติ
```

ผลลัพธ์จะเป็นไฟล์ `lib/firebase_options.dart`:

```dart
// firebase_options.dart (generated by flutterfire)
import 'package:firebase_core/firebase_core.dart' show FirebaseOptions;
import 'package:flutter/foundation.dart'
    show defaultTargetPlatform, kIsWeb, TargetPlatform;

class DefaultFirebaseOptions {
  static FirebaseOptions get currentPlatform {
    if (kIsWeb) {
      return web;
    }
    switch (defaultTargetPlatform) {
      case TargetPlatform.android:
        return android;
      case TargetPlatform.iOS:
        return ios;
      case TargetPlatform.macOS:
        return macos;
      case TargetPlatform.windows:
        throw UnsupportedError(
          'DefaultFirebaseOptions have not been configured for windows',
        );
      case TargetPlatform.linux:
        throw UnsupportedError(
          'DefaultFirebaseOptions have not been configured for linux',
        );
      default:
        throw UnsupportedError(
          'DefaultFirebaseOptions are not supported for this platform.',
        );
    }
  }

  static const FirebaseOptions web = FirebaseOptions(
    apiKey: 'YOUR_WEB_API_KEY',
    appId: '1:123456789:web:abcdef',
    messagingSenderId: '123456789',
    projectId: 'my-flutter-app',
    authDomain: 'my-flutter-app.firebaseapp.com',
    storageBucket: 'my-flutter-app.appspot.com',
  );

  static const FirebaseOptions android = FirebaseOptions(
    apiKey: 'YOUR_ANDROID_API_KEY',
    appId: '1:123456789:android:abcdef',
    messagingSenderId: '123456789',
    projectId: 'my-flutter-app',
    storageBucket: 'my-flutter-app.appspot.com',
  );

  static const FirebaseOptions ios = FirebaseOptions(
    apiKey: 'YOUR_IOS_API_KEY',
    appId: '1:123456789:ios:abcdef',
    messagingSenderId: '123456789',
    projectId: 'my-flutter-app',
    storageBucket: 'my-flutter-app.appspot.com',
    iosClientId: 'YOUR_IOS_CLIENT_ID.apps.googleusercontent.com',
    iosBundleId: 'com.example.myapp',
  );
}
```

## Workshop: Firebase Connection Test

### Full Test App

```dart
// main.dart
import 'package:flutter/material.dart';
import 'package:firebase_core/firebase_core.dart';
import 'firebase_options.dart';

void main() async {
  WidgetsFlutterBinding.ensureInitialized();
  
  await Firebase.initializeApp(
    options: DefaultFirebaseOptions.currentPlatform,
  );
  
  runApp(const FirebaseTestApp());
}

class FirebaseTestApp extends StatelessWidget {
  const FirebaseTestApp({Key? key}) : super(key: key);
  
  @override
  Widget build(BuildContext context) {
    return MaterialApp(
      title: 'Firebase Test',
      theme: ThemeData(
        colorScheme: ColorScheme.fromSeed(seedColor: Colors.orange),
        useMaterial3: true,
      ),
      home: const FirebaseConnectionTestPage(),
    );
  }
}

// Connection Test Page
class FirebaseConnectionTestPage extends StatefulWidget {
  const FirebaseConnectionTestPage({Key? key}) : super(key: key);
  
  @override
  State<FirebaseConnectionTestPage> createState() => _FirebaseConnectionTestPageState();
}

class _FirebaseConnectionTestPageState extends State<FirebaseConnectionTestPage> {
  final List<TestResult> _results = [];
  bool _isTesting = false;
  
  @override
  void initState() {
    super.initState();
    _runTests();
  }
  
  Future<void> _runTests() async {
    setState(() {
      _isTesting = true;
      _results.clear();
    });
    
    // Test 1: Firebase initialization
    await _runTest('Firebase Core', _testFirebaseCore);
    
    // Test 2: Firebase App Info
    await _runTest('Firebase App Info', _testFirebaseAppInfo);
    
    // Test 3: Firestore connection
    await _runTest('Firestore', _testFirestore);
    
    // Test 4: Auth service
    await _runTest('Firebase Auth', _testFirebaseAuth);
    
    setState(() => _isTesting = false);
  }
  
  Future<void> _runTest(String name, Future<String> Function() testFn) async {
    setState(() {
      _results.add(TestResult(name: name, status: TestStatus.running));
    });
    
    try {
      final detail = await testFn();
      setState(() {
        _results[_results.length - 1] = TestResult(
          name: name,
          status: TestStatus.success,
          detail: detail,
        );
      });
    } catch (e) {
      setState(() {
        _results[_results.length - 1] = TestResult(
          name: name,
          status: TestStatus.failure,
          detail: e.toString(),
        );
      });
    }
    
    // Small delay between tests
    await Future.delayed(const Duration(milliseconds: 500));
  }
  
  Future<String> _testFirebaseCore() async {
    final app = Firebase.app();
    return 'Firebase app: ${app.name}\nProject: ${app.options.projectId}';
  }
  
  Future<String> _testFirebaseAppInfo() async {
    final app = Firebase.app();
    final options = app.options;
    return 'API Key: ${options.apiKey.substring(0, 10)}...\n'
        'App ID: ${options.appId}\n'
        'Project ID: ${options.projectId}\n'
        'Storage Bucket: ${options.storageBucket}';
  }
  
  Future<String> _testFirestore() async {
    // ทดสอบ Firestore connection
    // ต้อง import cloud_firestore package
    return 'Firestore connection test requires cloud_firestore package\n'
        '(Add to pubspec.yaml and run pub get)';
  }
  
  Future<String> _testFirebaseAuth() async {
    // ทดสอบ Firebase Auth
    // ต้อง import firebase_auth package
    return 'Firebase Auth connection test requires firebase_auth package\n'
        '(Add to pubspec.yaml and run pub get)';
  }
  
  @override
  Widget build(BuildContext context) {
    final passedCount = _results.where((r) => r.status == TestStatus.success).length;
    final failedCount = _results.where((r) => r.status == TestStatus.failure).length;
    
    return Scaffold(
      appBar: AppBar(
        title: const Text('Firebase Connection Test'),
        backgroundColor: Colors.orange,
        foregroundColor: Colors.white,
        actions: [
          IconButton(
            onPressed: _isTesting ? null : _runTests,
            icon: _isTesting
                ? const SizedBox(
                    width: 20,
                    height: 20,
                    child: CircularProgressIndicator(
                      strokeWidth: 2,
                      color: Colors.white,
                    ),
                  )
                : const Icon(Icons.refresh),
          ),
        ],
      ),
      body: Column(
        children: [
          // Summary bar
          if (_results.isNotEmpty && !_isTesting)
            Container(
              padding: const EdgeInsets.all(16),
              color: passedCount == _results.length
                  ? Colors.green[50]
                  : Colors.red[50],
              child: Row(
                mainAxisAlignment: MainAxisAlignment.center,
                children: [
                  Icon(
                    passedCount == _results.length
                        ? Icons.check_circle
                        : Icons.warning,
                    color: passedCount == _results.length
                        ? Colors.green
                        : Colors.red,
                  ),
                  const SizedBox(width: 8),
                  Text(
                    '$passedCount/${_results.length} tests passed'
                    '${failedCount > 0 ? ', $failedCount failed' : ''}',
                    style: TextStyle(
                      color: passedCount == _results.length
                          ? Colors.green[800]
                          : Colors.red[800],
                      fontWeight: FontWeight.bold,
                    ),
                  ),
                ],
              ),
            ),
          
          Expanded(
            child: ListView.builder(
              padding: const EdgeInsets.all(16),
              itemCount: _results.length,
              itemBuilder: (context, index) {
                return TestResultCard(result: _results[index]);
              },
            ),
          ),
        ],
      ),
    );
  }
}

enum TestStatus { running, success, failure }

class TestResult {
  final String name;
  final TestStatus status;
  final String? detail;
  
  const TestResult({
    required this.name,
    required this.status,
    this.detail,
  });
}

class TestResultCard extends StatelessWidget {
  final TestResult result;
  
  const TestResultCard({required this.result, Key? key}) : super(key: key);
  
  @override
  Widget build(BuildContext context) {
    return Card(
      margin: const EdgeInsets.only(bottom: 12),
      child: ExpansionTile(
        leading: _buildStatusIcon(),
        title: Text(
          result.name,
          style: const TextStyle(fontWeight: FontWeight.w600),
        ),
        subtitle: Text(
          _getStatusText(),
          style: TextStyle(color: _getStatusColor()),
        ),
        children: [
          if (result.detail != null)
            Padding(
              padding: const EdgeInsets.fromLTRB(16, 0, 16, 16),
              child: Container(
                width: double.infinity,
                padding: const EdgeInsets.all(12),
                decoration: BoxDecoration(
                  color: Colors.grey[100],
                  borderRadius: BorderRadius.circular(8),
                  border: Border.all(color: Colors.grey[300]!),
                ),
                child: Text(
                  result.detail!,
                  style: const TextStyle(
                    fontFamily: 'monospace',
                    fontSize: 12,
                  ),
                ),
              ),
            ),
        ],
      ),
    );
  }
  
  Widget _buildStatusIcon() {
    switch (result.status) {
      case TestStatus.running:
        return const SizedBox(
          width: 24,
          height: 24,
          child: CircularProgressIndicator(strokeWidth: 2),
        );
      case TestStatus.success:
        return const Icon(Icons.check_circle, color: Colors.green);
      case TestStatus.failure:
        return const Icon(Icons.error, color: Colors.red);
    }
  }
  
  String _getStatusText() {
    switch (result.status) {
      case TestStatus.running: return 'Testing...';
      case TestStatus.success: return 'Passed';
      case TestStatus.failure: return 'Failed';
    }
  }
  
  Color _getStatusColor() {
    switch (result.status) {
      case TestStatus.running: return Colors.blue;
      case TestStatus.success: return Colors.green;
      case TestStatus.failure: return Colors.red;
    }
  }
}
```

## Firebase Emulator Suite

### Development กับ Firebase Emulator

```dart
// ใช้ Emulator ระหว่าง development เพื่อไม่ต้องใช้ production data
import 'package:cloud_firestore/cloud_firestore.dart';
import 'package:firebase_auth/firebase_auth.dart';

Future<void> setupEmulators() async {
  const bool useEmulator = true;  // ตั้งเป็น false สำหรับ production
  
  if (useEmulator) {
    await FirebaseAuth.instance.useAuthEmulator('localhost', 9099);
    FirebaseFirestore.instance.useFirestoreEmulator('localhost', 8080);
  }
}

// main.dart
void main() async {
  WidgetsFlutterBinding.ensureInitialized();
  
  await Firebase.initializeApp(
    options: DefaultFirebaseOptions.currentPlatform,
  );
  
  // Setup emulators ก่อน runApp
  await setupEmulators();
  
  runApp(const MyApp());
}
```

## Firebase Security Rules

### Firestore Security Rules

```javascript
// firestore.rules
rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    
    // ทุกคนอ่านได้ แต่เฉพาะ authenticated users เขียนได้
    match /posts/{postId} {
      allow read: if true;
      allow write: if request.auth != null;
    }
    
    // เฉพาะ owner ที่อ่าน/เขียนได้
    match /users/{userId} {
      allow read, write: if request.auth != null 
                         && request.auth.uid == userId;
    }
    
    // Nested collections
    match /users/{userId}/notes/{noteId} {
      allow read, write: if request.auth != null 
                         && request.auth.uid == userId;
    }
    
    // Custom claims
    match /admin/{document=**} {
      allow read, write: if request.auth != null 
                         && request.auth.token.admin == true;
    }
    
    // Block all by default
    match /{document=**} {
      allow read, write: if false;
    }
  }
}
```

### Firebase Storage Rules

```javascript
// storage.rules
rules_version = '2';
service firebase.storage {
  match /b/{bucket}/o {
    
    // Public images
    match /public/{imageId} {
      allow read: if true;
      allow write: if request.auth != null
                   && request.resource.size < 5 * 1024 * 1024  // 5MB limit
                   && request.resource.contentType.matches('image/.*');
    }
    
    // User-specific files
    match /users/{userId}/{allPaths=**} {
      allow read, write: if request.auth != null 
                         && request.auth.uid == userId;
    }
  }
}
```


### Common Issues
```
1. google-services.json ไม่ถูก path
   → วางที่ android/app/ (ไม่ใช่ android/)

2. Bundle ID ไม่ตรงกับ Firebase
   → เปลี่ยน bundle ID ใน Firebase หรือ ใน app

3. SHA-1 fingerprint ไม่ได้ add
   → เพิ่มใน Firebase console สำหรับ Google Sign In
   → keytool -list -v -keystore ~/.android/debug.keystore -alias androiddebugkey

4. minSdkVersion ต่ำเกินไป
   → Firebase ต้องการ minSdkVersion >= 21
```
